Section titled “Marketplace”

The Marketplace lets you discover, install, and manage curated plugins that extend your agent with reusable skills, MCP servers, rules, and subagents.

Note

Cross-surface synchronization: Plugins installed in Antigravity 2.0 are automatically updated and displayed in the Antigravity CLI’s Installed tab.

Browse and install plugins
Section titled “Browse and install plugins”

To browse and install Marketplace plugins in Antigravity 2.0, follow these steps:

In the left sidebar, click the Customizations tab (below Scheduled Tasks):

Click the Marketplace tab to view available plugins:

Click any plugin card to inspect its details and bundled capabilities:

Click + on the plugin card to install it.

Manage installed plugins
Section titled “Manage installed plugins”

To inspect, toggle, or uninstall existing plugins:

In the Customizations panel, click the Installed tab:

Click the toggle switch beside any plugin to enable or disable it.

To uninstall a plugin, click the plugin card and select Uninstall.

Any plugins you install in Antigravity 2.0 automatically sync and appear in the Antigravity CLI’s Installed tab.
