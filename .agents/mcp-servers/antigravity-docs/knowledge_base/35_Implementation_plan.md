Section titled “Implementation plan”

The agent uses the implementation plan artifact to architect changes within your codebase to accomplish a task. These plans contain technical details on what revisions are necessary and are designed for you to review.

Note

Planning mode: You can explicitly trigger structured planning and generate an implementation plan artifact at any time using the /plan slash command.

The following example shows a plan generated by the agent:

Unless you have your artifact review policy set to Always proceed, the agent typically requests your review on the implementation plan before making the changes needed to complete your task. You can click Proceed either in the conversation or in the artifact header to immediately continue with the agent’s plan.

Often, the agent creates a plan that differs slightly from what you want. Antigravity supports commenting on these artifacts so you can provide feedback to the agent for any reason, such as reducing the scope of changes, using a different tech stack, or correcting any discrepancies.

Once you leave comments on the implementation plan, you can still click Proceed to continue with the agent’s plan. Alternatively, you can click Review in the artifact header to examine all comments and submit a message as feedback instead of proceeding directly.

Once you proceed or submit a review, the agent continues its work, either iterating on the implementation plan and requesting another review or beginning implementation.
