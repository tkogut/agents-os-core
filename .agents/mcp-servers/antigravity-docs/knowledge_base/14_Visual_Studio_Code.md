Visual Studio Code
Section titled “Visual Studio Code”

The Antigravity for Visual Studio Code extension brings the full agentic capabilities of Google Antigravity into VS Code. Converse with agents in dedicated side panels, review granular inline diffs, inspect interactive plans, and execute multi-step engineering tasks without leaving your editor.

1. Download VS Code
Get Visual Studio Code for macOS, Linux, or Windows if you don't have it yet.
2. Install Antigravity extension
Download the official Google Antigravity extension from the VS Code Marketplace.
Prerequisites
Section titled “Prerequisites”

Ensure that you meet the following prerequisites before installing the extension:

Visual Studio Code: Version 1.90 or later on macOS, Linux, or Windows.
Antigravity entitlement: A Google Account with any Antigravity plan (including the free tier) or an enterprise account enabled for Gemini Enterprise.
Installation and setup
Section titled “Installation and setup”

Complete the following steps to install the VS Code extension:

Open Visual Studio Code.
Open the Extensions sidebar (Ctrl+Shift+X on Windows and Linux, Cmd+Shift+X on macOS) or visit the Visual Studio Code Marketplace.
Search for Google Antigravity (published by Google).
Click Install.
Click the Antigravity icon in the Activity Bar to sign in and begin setup. The extension automatically installs the local agy backend service on first launch.
