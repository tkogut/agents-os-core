As we go deeper into the agent-first era, Antigravity is evolving to further empower developers. Antigravity 2.0 is a standalone desktop application tailored for managing AI agents that execute complex knowledge and coding tasks.

What is Antigravity 2.0?
Section titled “What is Antigravity 2.0?”

Antigravity 2.0 serves as your AI agents’ central command center, providing a unified platform to launch, monitor, and orchestrate their activities. Unlike its predecessor, the Agent Manager, Antigravity 2.0 is a standalone application that functions independently of an IDE.

Within this interface, you can orchestrate agents both synchronously and asynchronously to perform the following tasks:

Execute system commands
Perform file read and write operations
Conduct web searches
Integrate with external tools using skills and MCP servers
Manage subagents
Interact with Chrome
Create artifacts and implementation plans

Whether you’re performing deep research or building new applications, Antigravity offers a streamlined interface for all types of knowledge work.
