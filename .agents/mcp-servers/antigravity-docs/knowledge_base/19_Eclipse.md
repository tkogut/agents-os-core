Eclipse
Section titled “Eclipse”

The Google Antigravity extension, available on the Eclipse Marketplace, brings the Antigravity agent directly into Eclipse. Delegate complex coding tasks, run multi-step agentic workflows, and review proposed file changes without leaving your Eclipse workspace.

Note

The Google Antigravity extension for Eclipse is currently in Public Preview.

Prerequisites
Section titled “Prerequisites”

Ensure that you meet the following prerequisites before installing the extension:

Eclipse: Eclipse 2026-06 or later on macOS, Linux, or Windows.
Antigravity entitlement: a Google Account with any Antigravity plan (including the free tier) or an enterprise account enabled for Gemini Enterprise.
Installation and setup
Section titled “Installation and setup”

Complete the following steps to install the Google Antigravity extension in Eclipse:

Open Eclipse.
Click Help in the top menu bar, then select Eclipse Marketplace… from the drop-down menu.
Search for Google Antigravity (published by Antigravity Eclipse Publisher).
Click Install and finish the installation wizard.
Restart Eclipse when prompted. On first launch after installation, the Antigravity view opens automatically on the right side of the editor area. Confirm that you trust the project folders to continue.

To open or hide the Antigravity view at any time, select Antigravity > Toggle Chat in the top menu bar (or press Cmd+Option+E on macOS or Ctrl+Alt+K on Windows and Linux).

Authentication and sign-in
Section titled “Authentication and sign-in”

On first launch, follow the sign-in prompt in the Antigravity panel to authenticate in your browser:

Individual accounts: sign in with your personal Google Account.
Enterprise accounts: click Sign in with Gemini Enterprise, authenticate with your corporate identity (including BYOID and Workforce Identity Federation), then select your organization’s Google Cloud Project and Region when prompted.

To switch accounts, change authentication methods, or configure AI model and MCP server preferences later, select Antigravity > Settings… in the top menu bar.
