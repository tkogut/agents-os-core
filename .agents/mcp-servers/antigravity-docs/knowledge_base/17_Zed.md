Section titled “Zed”

Antigravity integrates directly into the Zed editor for high-performance, agentic editing within your native Rust-powered workflow.

Prerequisites
Section titled “Prerequisites”

Ensure that you meet the following prerequisites before installing the extension:

Zed: Version 0.140.0 or later on macOS or Linux.
Antigravity entitlement: A Google Account with any Antigravity plan (including the free tier) or Gemini Enterprise (enterprise support is in Preview).
Installation and setup
Section titled “Installation and setup”

Complete the following steps to install Antigravity in Zed:

Open Zed.
Open the Command Palette (Cmd+Shift+P on macOS, Ctrl+Shift+P on Linux and Windows).
Enter agent: open settings and press Enter.
Navigate to External Agents > Add > Install from Registry.
Search for Antigravity.
Click Install.
