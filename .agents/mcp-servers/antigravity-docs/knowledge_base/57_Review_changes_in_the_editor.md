Section titled “Review changes in the editor”

After the agent begins writing code within a conversation, a Review Changes section appears in the Agent panel’s bottom toolbar. Click it to open a pane in your editor where you can scroll through all of the changes that you and your agent made during the conversation.

Note

This page covers the Antigravity IDE. To review diffs and commit changes in the Antigravity App or the Antigravity CLI, see Review changes.

Just like with artifacts, you can comment on any of the file diffs to communicate with the agent.
